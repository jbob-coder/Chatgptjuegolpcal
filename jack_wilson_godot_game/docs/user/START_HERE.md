This folder is the normal user-facing view of the project. It is intentionally small. Detailed engineering state, provenance, QA evidence, and history remain in `project_control/` and verification code remains in `tests/` / `scripts/qa/`.

Read these files first:
- `CURRENT_STATUS.md` — concise project status and next work.
- `QUESTIONS_FOR_USER.md` — only decisions that actually require the user's attention.

These files are projections, not independent sources of truth. If a user-facing file conflicts with authoritative project-control state, the control state wins and the projection must be regenerated or repaired.

Game/runtime files are not stored here.
