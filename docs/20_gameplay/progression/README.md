# Progression Package — Gameplay Authority

Status: ACTIVE PACKAGE GUIDE / DESIGN ONLY
Last reconciled: 2026-09-02

## Purpose

Own generic player-power progression rules that apply across hunts, regions, settlements and equipment content.

This package exists to prevent progression from being redefined separately by:
- character levels;
- equipment crafting;
- weapon mastery;
- monster knowledge;
- hunter rank/reputation;
- harvest skill;
- future crystal technology;
- individual item scripts.

## Authority

Primary progression authority:
- `PLAYER_PROGRESSION_AND_EQUIPMENT_SYSTEM.md`

Related existing authorities:
- `/STATS_ATTRIBUTES_EFFECTS_SYSTEM.md` — attributes, derived stats, modifier pipeline, equipment/status/terrain effects;
- `/MECHANICAL_SYSTEMS_GUIDE.md` — generic hunt/combat/harvest/crafting mechanics;
- `/CRYSTAL_MUTATION_ECOSYSTEM_SYSTEM.md` — creature crystal/mutation ecology;
- `/CONTENT_DATA_GUIDE.md` — data-driven content/stable-ID direction;
- `/DESIGN_QUALITY_GATES_AND_DEPENDENCY_MATRIX.md` — cross-system quality gates.

## Ownership law

This package owns:
- progression vectors;
- power-growth philosophy;
- equipment progression structure;
- mastery/knowledge/rank boundaries;
- upgrade/refinement principles;
- anti-inflation caps;
- progression admission gates.

It does not own:
- exact damage formulas;
- exact AP economy;
- one weapon family's move list;
- one armor item's exact stats;
- Monster 01 anatomy;
- Region 01 topology;
- final human use of creature crystals until that world/mechanical decision is explicitly made.

## Core rule

**Progression should widen and deepen the player's tactical options faster than it increases raw numeric power.**

A late hunter should win because of better preparation, equipment choices, mastery, knowledge and execution—not because old monster anatomy or terrain mechanics have stopped mattering.
