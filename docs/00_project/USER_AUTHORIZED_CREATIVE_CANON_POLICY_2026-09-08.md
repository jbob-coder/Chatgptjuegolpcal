# User-Authorized Creative Canon Policy — 2026-09-08

Status: ACTIVE PROJECT DIRECTIVE
Scope: Unnamed Hunt RPG and downstream game/story canon decisions

## User directive

The user explicitly reactivated game work and granted permission to add/edit original game information so unresolved design/story blanks can be answered instead of remaining indefinitely open.

## Authority boundary

This permission does **not** convert invention into source evidence.

Three layers remain separate:
1. `SOURCE-REFERENCE-NOT-GAME-CONTENT` — quarantined novel/source files and exact reconstruction evidence.
2. `RECONSTRUCTION_FACT / UNKNOWN / INFERENCE` — evidence-preserving structured reconstruction.
3. `USER_AUTHORIZED_CREATIVE_CANON` — original game/story decisions selected to fill gaps for the shipped/original experience.

Creative canon must never overwrite an unresolved reconstruction field and then claim the source supplied it. If later source evidence answers the question differently, preserve the source answer in reconstruction and treat the game/story value as a deliberate divergence unless the user chooses to revise it.

## Allowed autonomous decisions

When the current game authority leaves a value genuinely open, the development process may select an original value when doing so is necessary to implement the current bounded layer, provided that the value:
- does not contradict verified game authority;
- does not import quarantined source identity;
- is labeled as original/user-authorized canon or reversible implementation choice where appropriate;
- is chosen from current geometry/system/balance evidence where possible;
- is documented with rationale and dependencies;
- remains reversible if it is prototype tuning rather than foundational canon.

Examples include bounded prototype ranges, costs, thresholds, names for original entities, missing original story connective tissue, and other game-owned values.

## Originality firewall remains mandatory

Permission to fill blanks does not authorize copying or lightly renaming source-novel identities.

Production still excludes:
- source character/faction/location/ability/item/tier terminology as shipped identity;
- recognizable one-to-one source character or relationship replacements;
- source-exclusive plot/dialogue/lore recreation;
- vampire content or disguised vampire mechanics;
- any quarantined source text as production dialogue/lore unless separately transformed into demonstrably original material under the originality authority.

## Unknown-resolution rule

For each open question, choose one of:
- `SOURCE_RESOLVED` — only when source evidence actually establishes the answer;
- `DERIVED_RESOLVED` — when a deterministic calculation from verified inputs establishes it;
- `USER_AUTHORIZED_CREATIVE_CANON` — when the game/story needs an original answer not established by source;
- `OPEN` — when resolving it is unnecessary or would create avoidable risk.

Do not force every reconstruction unknown closed merely because creative permission exists.
