# Batch 033 Summary — Universal Stat Scaling

The active chat-game stat model is redesigned around capability envelopes instead of treating a D20 attribute as raw physical magnitude.

Humans now have explicit reversible gameplay-calibrated biological ceilings per measurable channel. Kharvori receive a higher physical envelope consistent with existing canon, while exact multipliers remain labeled game balance rather than lore fact. Beasts require species/body-part records; there is no universal beast multiplier. Hybrids use channel-specific inheritance in ratio space and cannot exceed the stronger parental cap without an explicit synergy/mutation/resonance rule.

Every +20 UCR represents a doubling of a measurable capability relative to a declared human reference. Cognitive/social constructs use standardized USR rather than pretending that reasoning or charisma has a physical ratio zero. Fortune is isolated so ordinary luck cannot override causality.

Jack's legacy stats are preserved exactly and migrated to a new capability profile without mutating SAVE_000002 or advancing world time.
