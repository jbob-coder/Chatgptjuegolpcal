# Batch 033 — Universal Stat Scaling

Authority: explicit user directive, current active chat-game systems, current Crystal Era world records, and user-authored beast/combat specification.

Purpose: replace direct D20-as-magnitude behavior with an envelope-first universal capability model that scales consistently across humans, Kharvori, beasts, hybrids, abilities and equipment.

Non-goals: no SAVE_000002 mutation; no world-time advance; no raw source-novel reading; no new beast species canon; no retroactive story advancement.

Primary rules:
- capability feasibility before randomness;
- logarithmic ratio-scale UCR for measurable physical channels;
- standardized USR for non-ratio cognitive/social constructs;
- neutral/explicit UFR for fortune;
- species-specific biological soft/hard caps;
- allometric body-size normalization;
- augmentation separated from biology;
- hybrid traits inherited channel-by-channel;
- threat tier never creates stats;
- legacy D20 attributes preserved only for compatibility/migration.
