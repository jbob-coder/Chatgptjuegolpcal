# Jack Wilson: 2670 Prototype — Batch 032

First Godot conversion slice for the active Jack Wilson Original Campaign.

Run with Godot 4.7.x:

```text
Open godot_game/project.godot and press F6/F5.
```

Controls: WASD move, Shift sprint, Space jump, mouse look, Q Steal attempt, Esc release/capture mouse.

Implemented now: Jack's authoritative start state, first-person movement, the READY start-room shell, the READY second-floor corridor shell, collision, primitive furniture obstacles, HUD, and a non-resolving Steal contact gate.

Not implemented yet: downstream stair/entry/curb, NPC simulation, full Steal resolution, combat, inventory UI, quests, transport event, saves, streaming, or authoritative Drive promotion.
