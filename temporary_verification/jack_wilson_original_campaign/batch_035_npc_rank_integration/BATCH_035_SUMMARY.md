# Batch 035 Summary

Batch 035 closes the largest integration gap left by Batch 034: NPCs now have persistent rank-state slots and a governed reveal/comparison protocol.

Key behavior:
- Age/job title no longer becomes an invented ER/C/H/P value.
- Exact rank is generated only after a material trigger creates a bounded evidence ledger from established facts.
- Generated career/rank evidence persists and cannot be rerolled for plot convenience.
- Internal true rank and Jack-visible rank knowledge are separate.
- Introductions can show verified ranks, bounded estimates with confidence, or `?`.
- Combat comparisons use C + P/ECR + matchup; healing uses H + modality/context; raw strength uses UCR channels; broad experience uses ER.
- Higher rank never grants physical capability or guarantees victory.

The seven active start-district service NPCs receive rank-state records but no fabricated promotions.
